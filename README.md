# 解语花

> 给 Hana 的聊天加一朵会接话、会朗读、会在窗口卡住时轻轻敲门的樱花。
>
> 它以前叫「接个话」，插件 id 没变，老用户升级后可以直接沿用原来的设置。

## ⚠️ 先看这里

- 推荐回复、会话标题和「问问小花」会调用模型；语音朗读会调用语音模型，具体费用和数据去向取决于你选择的服务。
- 选择「直接发送」后，点中的文字会以你的名义发到目标对话。建议先用「复制」熟悉效果，再决定要不要打开直发。
- 桌面樱花需要本机 Python、PyQt6 和 QtSvg。它启动不了时，普通回复卡片仍然可以正常使用。
- 插件只在本机保存配置和语音收藏，不会把数据发给作者；模型和语音服务的隐私规则仍以你选择的服务商为准。

## 这是干什么的

小花回复完一段话，你可能正好想追问、吐槽、撒个娇，或者顺手交代下一件事，却一时想不到咋个开口。

我做的「解语花」会根据刚才的聊天，准备几句你可以直接发给小花的话。你可以把它放在回复下方，也可以让一朵小樱花住在桌面角落，想用时再点开。

它还慢慢长出了几样顺手的小工具：小花需要你拍板时会来问你，回复太长可以念给你听，对话卡在生成里可以帮你接回来，聊久了还可以给窗口换个贴切的标题。

## 它能做什么

### 💬 推荐回复

- 小花回复后生成 **2～4 条**贴着上下文的推荐话，默认 3 条。
- 推荐语言跟着对话走：中文对话出中文，英文对话出英文。
- 会尽量贴近你的语气词、口头禅、用词和标点习惯，少来空话、套话和端着的腔调。
- 推荐方向默认有 4 种：**追问/延伸、分享/感慨、行动/请求、玩笑/俏皮**。
- 每一档条数都能单独选择方向；觉得默认方向不合适，可以在设置页点「和小花聊一聊」，用自然语言讨论后预览修改，一键应用，也能随时恢复默认。
- 会对明显不合适的套话做一轮清理，宁可少给一条，也不硬凑一条没用的话。

### 🃏 回复卡片

这是默认展示方式。小花回复完后，推荐会附在回复下方，点一下就能复制或发送；卡片具体落在回复附近的位置由 Hana 决定，不保证正好是正文最后一行。

你可以选择：

- **每次都推荐**：每轮回复都生成，稳定省心。
- **看情况推荐**：由小花判断这轮是否适合继续聊，安静一些，偶尔没有卡片属于正常情况。
- **复制**：把推荐复制到剪贴板，自己粘贴后再改改。
- **直接发送**：点中哪句就发哪句；发送暂时不可用时，会自动退回复制并提示你。

![推荐回复卡片](assets/screenshot-card.png)

### 🌸 桌面解语花

打开设置页的「展示方式 → 解语花」，桌面角落就会飘出一朵手帐风樱花。

- 左键打开推荐面板，点「刷新推荐」才生成新的一批；面板会先显示上次留下的推荐，收起后不会继续偷偷生成。
- 自动跟随最近活跃的对话，也可以从最近 5 个对话里固定一个。
- 面板顶部会显示当前正在读取哪个对话；推荐、朗读和会话标题共用这个目标。
- 右键打开发送方式浮签，可以在「直接发出」和「复制」之间切换，也可以从那里关闭悬浮球。
- 樱花会对光标掠过、悬停和点击做出反应：枝条会随风轻摆，花瓣会落下来；打开面板后拖动它，面板和花朵会保持相对位置，花枝还会带一点滞后与回弹。
- 面板、朗读窗和提问窗都可以跟着樱花移动，靠近屏幕边缘时会自动换到更合适的一侧。
- 明暗主题会跟随 Hana，鼠标移开后面板会收得轻一点，仍然留在眼前找得到。

### ❓ 小花需要你拍板时

在悬浮球运行时，如果小花确实需要你在几个方案里选一个、确认要不要做某件事，解语花会把推荐区换成提问区：

- 单选：点一个就能回答。
- 多选：勾选多项后点「确认选择」，还会提示最少或最多选几项。
- 自定义回答：直接输入自己的想法。
- 跳过本题：暂时不回答，让小花自己继续。

你的回答会回到发起提问的那段对话，小花可以接着往下做。你在原对话里直接继续聊天时，旧问题会安静作废，不会重复追着问。

这个功能依赖桌面悬浮球；只使用回复卡片时不会弹出提问窗。普通的知识解释、观点判断和闲聊也不会被硬改成选择题。

### 🔁 窗口断联了，帮你接回来

悬浮球可以留意对话是否因为模型报错、生成异常结束、自动重试耗尽，或者长时间卡在思考里而中断。

- 出现异常时显示「窗口断联了」或「窗口卡住了」，并告诉你来自哪个对话。
- 点「继续哈」，就往那段对话发一条简短的「继续哈」，把话头接回来。
- 「自动续接」可以在面板里打开；默认关闭，检测到断联时先让你决定。
- 你自己主动停止生成，不会被误报成断联；连续失败时会自动收敛提醒，避免一遍遍打扰。

### 🎙️ 语音朗读

在设置页打开「语音朗读」后，悬浮球的「对话工具」里会出现「念给我听」。它会打开独立朗读窗：

- 自动跟随最近活跃对话，或手动固定最近 5 个对话。
- 默认选最新一条回复，也可以从前 5 条回复里挑一条。
- 点「刷新」重新读取当前对话的回复列表；刷新不会自动合成，真正点「朗读」才会用额度。
- 支持播放、暂停、继续和从头重听。
- 朗读内容可以选「整条回复」，也可以只读引号里的台词，适合角色扮演。
- 朗读前会去掉界面隐藏的思考区和内部标记，不把这些内容念出来。
- 朗读过的内容可以点「♡ 收藏」保存为本地音频；设置页的「语音收藏」会按来源分组，可试听、删除，播放收藏不会重新合成。
- 可以给不同对话角色分别选择音色；没有专属设置时跟随模型默认音色。
- 语速可以在设置页调整，试听走系统播放，不依赖网页自动播放。

语音模型有三种来源：自动使用 Hana 里已经配好的语音模型、从候选模型里手动选择、自己配置接口。自定义接口支持 MiniMax `t2a_v2` 和 OpenAI 兼容聊天接口（例如 MiMo）。

### 🏷️ 给会话换个标题

悬浮球的「会话标题」工具可以读当前目标对话，生成一个短而贴切的新标题并写回 Hana。

- 标题会跟着对话语言走。
- 生成失败时不会把附件信息或隐藏内容当成标题。
- 生成过新标题后会出现「还原」，可以退回上一次的标题。

### ❓ 问问小花

这是悬浮球里的 Hana 使用问题快捷入口，默认关闭，需要时在设置页打开。

你可以直接问「怎么归档旧会话」「模型要去哪里配」「插件怎么设置」这类问题，答案会在独立小窗里显示，不会把问题塞进真实聊天记录，也不会打断当前对话。

这里使用的是 **Hana 内置 `user-guide` 使用说明的快捷整理版**。说明书本身随 Hana 提供，解语花负责把它变成一个更容易找到、随手能问的入口。

### 🤝 和闲不住的悬浮球一起用

如果你同时使用闲不住，解语花支持接入它的悬浮球协调。两个悬浮球不会抢着重复启动，融合后仍能保留推荐、提问和朗读这些入口。

## 它怎么配

### 推荐模型

在设置页右上角打开「模型设置」，有三种选择：

1. **跟随当前对话模型**：默认选项，不用额外配置。
2. **从 Hana 已配置的模型里选**：可以挑一个更轻量、更省钱的模型专门生成推荐。
3. **自定义 API**：填写接口地址、密钥和模型名。

模型设置里有「测试一下」按钮。测试只做一次临时调用，不会因为测试把新密钥写进配置；已经保存的密钥留空即可继续使用，点「清除已保存的 Key」才会删除。

### 其他开关

设置页里的选项都会即时保存：

- 展示方式：回复卡片 / 解语花 / 关闭。
- 推荐时机：每次都推荐 / 看情况推荐。
- 推荐条数：2 / 3 / 4。
- 推荐方向：按条数选择，支持和小花聊一聊后修改。
- 点一下之后：直接发送 / 复制。
- 问问小花：默认关闭。
- 语音朗读：单独开启和配置。

## 安装与第一次使用

1. 下载最新 zip 安装包。
2. 把 zip 拖进 Hana 窗口，或放进插件目录后重启 Hana。
3. 打开插件抽屉里的「解语花」设置页。
4. 不想折腾的话保持默认设置，直接去和小花聊天就行；推荐模型默认跟随当前对话模型。
5. 想用桌面樱花，选择「展示方式 → 解语花」。如果提示缺少依赖，先确认 Python 可用，再安装 PyQt6：

   ```powershell
   python -m pip install PyQt6
   ```

升级时会保留原来的设置和收藏；旧版「接个话」留下的配置也会继续迁移使用。

### 暂时不用 / 卸载

- 只想安静一阵：在设置页选择「关闭」，不会再生成推荐。
- 想关掉桌面樱花：在面板右键选择关闭，或在设置页停止解语花。
- 要彻底移除：从 Hana 的插件管理中停用或卸载。Hana 的聊天记录不属于解语花，插件不会替你删除。

## 隐私与数据

解语花不向作者上传数据，也没有自己的远程账号系统。不同功能会读取不同范围的本地内容：

- **推荐回复**：主要取当前目标对话最近 4 条可见消息，每条会做长度限制，并清掉界面隐藏的思考区、引用块和内部注入标记，再发送给你选择的模型。
- **会话标题**：读取当前目标对话，用来提炼标题；标题生成只把结果写回 Hana 的会话标题。
- **语音朗读**：只读取你选择的那条小花回复，清理排版标记后送到语音服务；收藏的音频留在本机，之后播放不重新合成。
- **问问小花**：把你输入的问题和 Hana 内置说明书的相关内容交给解语花配置的模型回答，不带入真实聊天记录。
- **直接发送**：你点中的推荐会作为一条真实用户消息发送到目标对话；提问面板里的回答也会回到对应对话继续处理。
- **检查更新**：只有你点击「检查更新」时才请求 GitHub 的公开接口。

模型和语音内容只会发往你选定的服务：跟随当前对话模型、Hana 已配置的模型，或你自己填的接口。插件作者看不到这些请求。

自定义模型和语音的 API Key 只保存在本机插件数据目录：

- Windows 使用系统 DPAPI 加密保存。
- 页面和接口只显示「已保存」掩码，不会把 Key 原样返回。
- 留空保存不会覆盖旧 Key，明确点击清除才会删除。
- 旧版留下的受保护 Key 会在启动后尝试自动迁移。
- 如果系统加密不可用，会使用兼容性明文兜底，请不要把插件数据目录同步到公共网盘。

## 常见问题

### 卡片怎么不出现？

1. 确认设置页「展示方式」选的是「回复卡片」。
2. 点「模型设置 → 测试一下」，确认模型能正常返回。
3. 如果选的是「看情况推荐」，这一轮没有卡片可能只是小花判断不适合继续聊；想稳定出卡，改成「每次都推荐」。
4. 旧版 Hana 会使用兼容卡片，新版 Hana 会使用更完整的内联卡片，位置可能略有不同。

### 悬浮球没有出现？

确认「展示方式」选的是「解语花」，再看设置页里的运行状态。若提示缺少 Python 或 PyQt6，先安装依赖；这不会影响回复卡片模式。

### 提问面板为什么没弹？

提问功能只在桌面解语花正在运行时生效。小花普通回答知识、解释观点或陪你闲聊时，也不会为了弹窗强行把话题变成选择题。

### 点了直接发送却失败？

先确认目标对话仍然存在、没有正在生成。回复卡片会自动退回复制；悬浮球会给出失败提示，可以稍后再点「继续哈」或改用复制。

### 朗读没有声音？

先在「语音朗读」里保存模型，再点「测试模型连接」。

- 自动模式需要 Hana 里已经配置可用的语音模型。
- MiniMax 自定义模式需要 API Key 和 GroupId。
- OpenAI 兼容聊天模式需要对应的接口地址、模型名和 API Key。
- 试听和正式朗读都由系统播放器播放，不是网页静音；若仍无声，换一个音色或检查系统音量。

## 兼容性

- Hana 桌面版 **0.450.0+**。
- Hana **0.450.0～0.680.8**：使用兼容 iframe 卡片。
- Hana **0.680.9+**：使用内联 Interactive Card；直接发送暂时不可用时会自动复制兜底。
- 桌面悬浮球需要 Python、PyQt6 和 QtSvg；缺少依赖时不影响回复卡片。
- 生成推荐需要一个可用的模型；默认跟随当前对话模型，无需额外配置。
- 语音朗读需要额外的语音模型或自定义语音接口，是否收费由对应服务商决定。

## 开发

本项目没有额外的 Node 依赖，JavaScript 使用 Node 内置测试模块，悬浮球使用 Python + PyQt6。

```powershell
node --test --test-concurrency=1 tests/*.test.js
python tests/run_all.py
```

测试覆盖推荐解析与清洗、配置迁移、模型和语音配置、会话目标、卡片发送、提问与断联续接状态、朗读选择与收藏，以及悬浮球的关键交互状态。
