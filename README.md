# 解语花

一个 Hana Agent 插件，作用是在你和小花（或者其他助手）聊天时以卡片形式生成几个推荐回复~（懒癌或者抓耳挠腮找不到话题患者的福音了说是）

> 📝 它以前叫「接个话」，现在正式更名「解语花」啦。

## 这是干什么的

和 小花 聊天，可能会聊完一句不知道该接什么。装上「解语花」之后，小花回复中多一张小卡片，上面有几条「你可能想说的话」——点一下就直接以你的名义发出去，不用打字。（也可以切到复制模式，点一下复制到剪贴板，自己粘贴后再改改。）

有几个必须注意的点！

1. 新版 Hana 会把推荐渲染成真正的内联卡片；较旧的公开版会自动走兼容卡片。卡片都附在回复下方，不保证出现在正文最后一行。
2. 选择「点一下复制」的话，只能复制到剪贴板，需要自己粘贴到对话框内
3. 选择「直接发送」的话，Card Host 如果暂时不可用，会自动退回复制，避免消息悄悄丢掉

## 它能做什么

- 💬 **推荐回复**：小花回复后自动生成 2~4 条口语化的接话，附在回复下方
- 🌸 **桌面解语花**：一朵会接话的樱花悬浮在桌面角落，点开面板直接挑话发出去，不占对话流（设置页「展示方式」可选）
- ❓ **会提问了**：小花需要你拍板时（选方案、确认方向、补信息），桌面解语花会直接弹出提问面板——选项、自定义输入、跳过随你选，你的回答自动回传给小花继续干活（交互参考了 dsh 的 ask_user_question）
- 🏷️ **重命名标题**：面板里一键总结整段对话，给这个对话框起个贴合内容的新标题；起错了点「退回」还原
- 🔁 **断联续接**：对话意外中断时，桌面解语花给出一张小卡，一键把话头接回来；也可以打开自动续接
- 👁️ **当前会话可见**：面板顶部显示正在读取的是哪个对话框，跟随最近活跃还是手动固定都一目了然
- 🖱️ **点一下就能用**：点击推荐复制到剪贴板，自己粘一下再发；也可以设置成「直接发送」
- 🔁 **每次都推荐（默认）**：每轮回复都带，方便稳定，多花一点模型费用
- 🧠 **看情况推荐**：助手觉得这轮适合接话才出推荐，不打扰；但出不出看模型的自觉，偶尔可能不出卡
- 🎛️ **模型自己选**：默认跟随当前助手模型（用的就是你正在聊天的那个模型，不用额外配置），也可以单独配一个便宜模型来生成推荐（更省钱），或者用自定义 API
- 📦 **检查更新**：设置页一键看有没有新版本

## 安装

1. 下载 zip 包
2. 拖进 Hana 窗口，或放到插件目录后重启 Hana
3. 打开插件抽屉的「解语花」设置页，按需调整（不调整也能直接用）

## 使用

- 默认就是开着的：小花回复里会出现推荐卡片，点一下就复制，粘一下就能发
- 不想看推荐了：设置页关掉「解语花」，或切到「看情况推荐」让它安静点
- 卡片一直没出现？先看设置页总开关是不是开着，再点右上角「模型设置」里的「测试一下」验证模型通不通
- ❓ **提问弹窗怎么触发？** 小花需要你拍板时，桌面解语花（悬浮球）会自动展开提问面板。注意：**提问功能依赖悬浮球，需要先启动桌面解语花才生效**——只用推荐卡片模式（展示方式选「卡片」）看不到提问面板
- 🔁 **断联续接怎么用？** 悬浮球模式下，对话意外中断会弹出「窗口断联了」小卡，点「继续」即可重连；自动续接开关默认关闭，想让它自己尝试时再打开

## 隐私

- 推荐由模型生成，需要把**最近几句对话**发给模型。模型来源有三种：
  - **跟随助手**：用你正在聊天的那个模型，对话本来就在它手里
  - **从已配置的模型里选**：用你在 Hana 里配过密钥的供应商
  - **自定义 API**：用你自己填的地址和密钥
- 数据只发给你自己选择的模型服务，**插件作者收不到任何东西**
- 插件本身不收集任何数据，所有配置存在本地
- 自定义 API 的 Key 保存在本机插件数据目录：Windows 下使用系统 DPAPI 加密；非 Windows 或系统锁不可用时为明文兜底，请不要把插件数据目录同步到公共网盘
- 旧版本留下的 `enc:` 混淆 Key 会在插件启动后尝试自动迁移，不会突然要求重新输入
- 页面和配置接口只返回「已保存」掩码，不返回 Key 本身；留空保存不会覆盖旧 Key，设置页可以明确清除
- 点击「直接发送」时，你选中的那条话会以你的名义发送到当前会话

## 常见问题

**卡片怎么不出现？**

1. 看设置页「解语花」总开关是不是开着
2. 点右上角「模型设置」→「测试一下」，能出文字说明模型没问题
3. 「看情况推荐」模式靠助手自己判断，偶尔没出是正常的；想要稳定出卡就切「每次都推荐」

**点一下没反应？**

- 复制模式下点一下是复制到剪贴板，不会直接发出去，去输入框粘贴就行
- 换新窗口后旧卡片可能失效，重新生成一张就行

**生成的推荐不想要？**

- 推荐只是建议，发不发你说了算；直接忽略卡片就行
- 觉得方向不对，设置页可以跟小花聊聊怎么调

## 兼容性

- Hana 桌面版 **0.450.0+**
- Hana **0.450.0～0.680.8**：使用兼容 iframe 卡片
- Hana **0.680.9+**：使用 Interactive Card；直接发送失败时自动复制兜底
- 悬浮球另需要本机 Python + PyQt6；缺少依赖时不影响回复卡片
- 生成推荐需要配置模型（默认跟随当前助手，无需额外配置）

## 说明

- 推荐只是建议，发不发你说了算
- 生成推荐会额外消耗一次模型调用，选便宜模型更划算
